# Конструктор портала для Jira Service Management

Плагин даёт собрать свою страницу клиентского портала Jira Service Management **4.21.1** (Jira **8.21.1**). Байткод собран под **Java 8**. Опубликованная страница целиком заменяет список порталов и страницу проекта. Штатную разметку Jira конструктор не перекрашивает. Форма заявки и страница входа остаются страницами Jira.

## Что можно менять

- Общий стиль для всех порталов и отдельный стиль для конкретного портала.
- Цвета, шрифт, ширину, скругление, тень, фон.
- Шапку своей страницы: логотип, название, ссылки. У гостя кнопка входа, у вошедшего посетителя его имя, заявки и выход. Режим «скрыть» убирает шапку.
- Обложку: заголовок, подзаголовок, высота, фон, затемнение. Текст правится прямо в макете.
- Свой поиск по кнопкам услуг и сами кнопки: сетка или список, число колонок, описания. Порядок кнопок меняется перетаскиванием одной кнопки на другую.
- Полосу объявления и подвал с колонками ссылок.
- Свой HTML в шапке и подвале. Скрипты, обработчики и `javascript:` вырезаются.
- Свой CSS в конце темы. `@import`, `expression` и опасные `url()` вырезаются. Произвольный JavaScript плагин не подключает.
- Телефон и планшет: свои колонки, высота обложки, поля, размер текста и высота шапки. Границы брейкпоинтов настраиваются. В предпросмотре это настоящие media query, а не отдельная картинка.

Пока стиль не отмечен как опубликованный, посетители видят обычный портал.

## Как открыть

1. Администрирование Jira → Приложения → Установить приложение и загрузить `portal-designer-1.3.0.jar`. Если стоит более ранняя сборка, замените jar: тот же номер версии Jira не обновит.
2. В карточке плагина нажать **Настроить**, либо открыть **Администрирование → Клиентский портал → Конструктор портала**.
3. Выбрать «Все порталы» или конкретную службу поддержки. Если идентификатор портала в адресе отличается от id службы, его можно вписать вручную.
4. Собрать страницу из блоков слева: шапка, обложка, поиск, карточки, свои текстовые блоки и ссылки. Порядок меняется перетаскиванием блока.
5. Нажать **Сохранить**, чтобы посетители увидели эту страницу. Кнопка **Портал Jira** сразу выключает плагин и возвращает обычный портал.
6. Открыть `/servicedesk/customer/portal/{id}` и обновить страницу.

Макет переключается между главной, входом и формой заявки, а также между компьютером (1180), планшетом (820) и телефоном (390). Клик по блоку макета открывает его настройки. Заголовки обложки, шапки, объявления и подписи подвала можно править прямо в макете.

На телефоне и планшете поля размера относятся к этому экрану. На компьютере те же поля задают базовые значения.

Кнопки **Импорт** и **Экспорт** переносят JSON темы между стендами. `Ctrl/Cmd+S` сохраняет, `Ctrl/Cmd+Z` отменяет шаг редактора.

## Как стиль попадает на портал

Клиентский портал JSM 4.21 — одностраничное приложение. Плагин:

- подключает `portal.js` и `portal.css` в контексты `customerportal` и `servicedesk.portal`;
- дополнительно вставляет тот же скрипт фильтром в HTML `/servicedesk/customer/*`, если контекст на странице не вызвался;
- забирает опубликованную тему с `GET /rest/portal-designer/1.0/public-theme` (доступен без входа, в ответе только внешний вид);
- на списке порталов и на странице проекта читает ссылки Jira один раз, собирает из темы свою страницу (`#pd-page`: шапка, обложка, поиск, кнопки услуг, подвал) и скрывает штатную разметку;
- на форме заявки и на входе ничего не подменяет: поля остаются полями Jira.

Порядок кнопок хранится в теме (`requests.order`), а не в селекторах React.

Тема хранится в глобальных plugin settings, то есть в базе Jira. На Data Center узлы читают одну и ту же запись, локальных файлов нет.

## Сборка

Нужны JDK 8 или новее (компилятор выпускает байткод 8) и Maven.

```bash
mvn -DskipITs package
```

Готовый артефакт: `target/portal-designer-1.3.0.jar`.

Проверка без установленной Jira — локальный редактор на том же коде темы:

```bash
mvn -DskipTests test-compile exec:java \
  -Dexec.classpathScope=test \
  -Dexec.mainClass=com.portaldesigner.dev.DesignPreviewServer
```

Если `exec-maven-plugin` не подключён:

```bash
mvn -DskipTests test-compile
java -cp "target/classes:target/test-classes:$(mvn -q dependency:build-classpath -DincludeScope=test -Dmdep.outputFile=/dev/stdout)" \
  com.portaldesigner.dev.DesignPreviewServer 8765
```

Редактор откроется на `http://127.0.0.1:8765/plugins/servlet/portal-designer`. Этот сервер не входит в jar.

## Права и границы

Редактор и запись темы доступны только администраторам Jira. Клиентский портал читает уже опубликованный документ.

Плагин не подменяет движок заявок, базу знаний и вложения. Страница, собранная в конструкторе, заменяет список порталов и страницу проекта. Форма заявки и вход остаются страницами Jira.
