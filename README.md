# Конструктор портала для Jira Service Management

Плагин даёт править клиентский портал Jira Service Management **4.21.1** (Jira **8.21.1**). Байткод собран под **Java 8**. Пока не включено «Заменить оформление», посетитель видит свой портал: шапка, цвета и карточки Jira остаются. Перетаскивание кнопки на другую кнопку в том же ряду меняет их местами. Готовый стиль или галочка оформления включают полную тему.

## Что можно менять

- Общий стиль для всех порталов и отдельный стиль для конкретного портала.
- Цвета, шрифт, ширину, скругление, тень, фон.
- Шапку: своя сборка, перекраска штатной или скрытие. Логотип, название, ссылки, кнопка входа.
- Обложку главной: заголовок, подзаголовок, высота, фон, затемнение. Текст правится прямо в макете.
- Поиск, плитку заявок (сетка или список, число колонок, описания).
- Полосу объявления и подвал с колонками ссылок.
- Свой HTML в шапке, подвале и отдельных блоках. Скрипты, обработчики и `javascript:` вырезаются.
- Свободное положение на холсте: шапку, обложку, поиск, карточки, подвал и свои блоки можно перетащить и изменить в размере отдельно для компьютера, планшета и телефона. Любой из этих блоков можно скрыть.
- Любой объект страницы: клик по нему задаёт размер, скругление, шрифт, цвет, заливку и положение. Правило действует на той странице, где объект выбран, и на опубликованном портале ищет этот же объект по месту в разметке. Объект, выбранный в версии 1.0.8, нужно выбрать ещё раз: старая метка существовала только внутри конструктора.
- Свои блоки: текст, картинка, кнопка, HTML и всплывающая подсказка. Подсказка привязывается к объекту и открывается при наведении. Блок можно ограничить главной, запросами, формой заявки, входом или всеми страницами.
- Меню портала и меню проекта собираются заново: свои пункты, порядок, строка или столбец, цвет, шрифт, скругление. 0 у скругления делает углы прямыми. Меню перетаскивается по странице.
- Форма заявки: каждое поле, подпись и кнопка перетаскиваются отдельно. Общий цвет, шрифт и скругление задаются в разделе «Форма заявки». Сетка карточек на форму не ставится.
- Свой CSS в конце темы. `@import`, `expression` и опасные `url()` вырезаются. Произвольный JavaScript плагин не подключает.
- Телефон и планшет: свои колонки, высота обложки, поля, размер текста и высота шапки. Границы брейкпоинтов настраиваются. В предпросмотре это настоящие media query, а не отдельная картинка.

Галочка **Новый дизайн** сразу включает и выключает оформление. Пока она снята, посетители видят обычный портал, черновик остаётся. **Удалить оформление** стирает сохранённую тему. После переключения обновите страницу портала.

## Как открыть

1. Администрирование Jira → Приложения → Установить приложение и загрузить `target/portal-designer-1.1.0.jar`. Если уже стоит предыдущая версия, загрузите новый jar поверх: тот же номер версии Jira может не обновить.
2. В карточке плагина нажать **Настроить**, либо открыть **Администрирование → Клиентский портал → Конструктор портала**. Страница открывается внутри админки Jira: сверху общая шапка, слева меню раздела «Управление приложениями», пункт «Конструктор портала» выбран. Оболочку рисует декоратор `atl.admin`, а не отдельное окно.
3. Выбрать «Все порталы» или конкретную службу поддержки. Если идентификатор портала в адресе отличается от id службы, его можно вписать вручную.
4. Собрать стиль и включить **Новый дизайн**. Галочка сохраняется сразу. Остальные правки — кнопкой **Сохранить**.
5. Открыть `/servicedesk/customer/portal/{id}` и обновить страницу.

Макет — это сам клиентский портал в рамке (`?pdPreview=1`), с вашими проектами и запросами. Переключатель страниц открывает список порталов, запросы, вход и форму. Кнопка **Переход** позволяет идти по ссылкам портала; без неё клик выбирает объект в разделе «Объект». Если портал нельзя встроить в рамку, редактор один раз возвращается к схематичному макету. Ширина макета: компьютер 1180, планшет 820, телефон 390.

Блок двигается, если потянуть его сам или синюю плашку над ним. Угол меняет ширину и высоту. Пока блок не сдвинут, он остаётся в обычном потоке. Раздел «Холст» добавляет свои блоки и прячет штатные. Кнопка «Блок» в верхней панели сразу добавляет текстовый блок.

На телефоне и планшете поля размера относятся к этому экрану. На компьютере те же поля задают базовые значения.

Кнопки **Импорт** и **Экспорт** переносят JSON темы между стендами. `Ctrl/Cmd+S` сохраняет, `Ctrl/Cmd+Z` отменяет шаг редактора.

## Как стиль попадает на портал

Клиентский портал JSM 4.21 — одностраничное приложение. Плагин:

- подключает `portal.js` и `portal.css` в контексты `customerportal` и `servicedesk.portal`;
- дополнительно вставляет тот же скрипт фильтром в HTML `/servicedesk/customer/*`, если контекст на странице не вызвался;
- забирает опубликованную тему с `GET /rest/portal-designer/1.0/public-theme` (доступен без входа, в ответе только внешний вид);
- ставит CSS-переменные и помечает шапку, поиск, карточки и подвал уже после отрисовки SPA, включая переходы по `history`.

Скрипт не переносит узлы React. Без галочки «Заменить оформление» на портал попадают только явные правки: порядок кнопок, сдвинутые объекты и свои блоки. Цвет, шрифт, шапка и сетка карточек включаются этой галочкой или готовым стилем. Шапка и подвал на запросах и в профиле включаются галочкой в разделе «Шапка». Сетка карточек остаётся только на списке проектов и на странице проекта. Снятие публикации убирает поставленные стили и координаты. Тема, сохранённая в предыдущей версии без этого переключателя, больше не подменяет портал.

Тема хранится в глобальных plugin settings, то есть в базе Jira. На Data Center узлы читают одну и ту же запись, локальных файлов нет.

## Сборка

Нужны JDK 8 или новее (компилятор выпускает байткод 8) и Maven.

```bash
mvn -DskipITs package
```

Готовый артефакт: `target/portal-designer-1.1.0.jar`.

Проверка без установленной Jira — локальный редактор на том же коде темы:

```bash
mvn -DskipTests test-compile exec:java \
  -Dexec.classpathScope=test \
  -Dexec.mainClass=com.portaldesigner.dev.DesignPreviewServer
```

Если `exec-maven-plugin` не подключён:

```bash
mvn -DskipTests test-compile
java -cp "target/classes:target/test-classes:$(mvn -q dependency:build-classpath -DincludeScope=test -Dmdep.outputFile=/dev/stdout)" \
  com.portaldesigner.dev.DesignPreviewServer 8765
```

Редактор откроется на `http://127.0.0.1:8765/plugins/servlet/portal-designer`. Этот сервер не входит в jar. Локально он подставляет такую же оболочку, как декоратор админки: шапку и боковое меню. В установленной Jira эти части рисует сама Jira.

## Права и границы

Редактор и запись темы доступны только администраторам Jira. Клиентский портал читает уже опубликованный документ.

Плагин не подменяет движок заявок, базу знаний и вложения. Полный визуальный каркас портала (шапка, обложка, карточки, подвал, адаптив, свой HTML и CSS) настраивается здесь; поля заявки остаются полями Jira.
